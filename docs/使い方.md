# 使い方

インストール方法は [セットアップ手順](セットアップ手順.md)、動く仕組みは [仕組み](仕組み.md) にある。

## 始める、終える

| やりたいこと | Claude Code での入力 |
|---|---|
| 音声で会話する | `/10-voice`、または「音声で会話しよう」 |
| 会話を終える | 「終わり」と言う |
| 使わない日に、サービスを止める | `/10-voice off` |
| 状態を見る | `/10-voice status`(読み上げのメモリの量も出る) |
| 話し方を分析する | `/10-voice review`(日付を付けると、その日の分) |

起動直後は、メモリを 3GB ほど使う。読み上げ(Kokoro)は使うほどメモリが増えるので、8GB を超えたら、自動で再起動して戻す(下の「読み上げのメモリを戻す」)。`off` は、ログイン時の自動起動も解除する。

## 話す

右 ⌘ キーを押している間だけ、マイクが開く。

| 場面 | 操作 |
|---|---|
| 話す | 右 ⌘ キーを押し、合図音(約 1 秒後)が鳴ってから話す |
| 話し終える | キーを離す。合図音が鳴り、発言が Claude に渡される |
| 考えて黙る | キーを押したままにする。一瞬離れても、0.5 秒以内に押し直せば続きになる |
| Claude の読み上げを止める | 読み上げ中に、キーを 0.5 秒ほど押し続ける。合図のあとに話せる |
| 読み上げを聞き直す | 字幕ウィンドウの左下のつまみを動かす |

知っておくこと:

- Claude が作業している間は、会話はできない。話しかけるのは、次の読み上げが終わってからにする
- ⌘ と数字のようなショートカットは、話すための操作として扱わない。読み上げも止まらない
- キーを押して読み上げを止めても、何も話さなければ、少し手前から続きを読む
- 押して話したのに聞き取れなかったときは、低い音が鳴る。もう一度、押して話す
- 8 分のあいだ何も話さないと、Claude は声をかけずに、そのまま聞き取りを続ける。時間の制限はなく、戻ってきたら、いつものように話せば届く。この間、ほかのセッションは話しかけてこない(話したいセッションがあれば、字幕ウィンドウでそのタブを押す)

### キーを使わない方式

キーボードに手が届かないときは、字幕ウィンドウの「⌘ キー」のボタンを押すと、「以上」と言うまで聞き続ける方式に変わる。もう一度押すと戻る。方式は、開いているすべての Claude Code で共通で、押すとその場で切り替わる。

| 場面 | 操作 |
|---|---|
| 話す | 合図音が鳴ってから話す。黙っていても、聞き取りは切れない |
| 話し終える | 「以上」と言う(「以上です」でもよい) |
| Claude の読み上げを止める | 読み上げ中に話しかける |
| マイクを閉じる | 「ミュート」とだけ言う。再開は `/10-voice` |

この方式では、マイクが開いたままになる。「三つ以上」「これ以上」のように、数量や比較に続く「以上」では終わらない。咳や物音で読み上げが止まったら、「続けて」と言う。

## 字幕ウィンドウ

読み上げた内容と、認識された自分の発言が、画面上のウィンドウ(字幕ウィンドウ)に表示される。ほかのアプリより手前に表示される。

| 部品 | 働き |
|---|---|
| タブ | Claude Code を複数開いていると、1 つずつ並ぶ。押すと、そこが話す相手になり、ほかは止まって待つ。「すべて」を押すと、順番に話す状態に戻る |
| 「いま話す」「あとで」 | タブをつまんで「あとで」へ移すと、戻すまで話しかけてこない |
| タブの丸 | 緑は会話中、橙は話したくて待っている、青の輪は裏の作業を待っている(押すと話しかけられる)、灰は作業中など |
| ⏸ 停止 | すべての会話を止める。会議のときに使う。▶ 再開で戻る |
| メモリ | 読み上げ(Kokoro)が使っているメモリ。8GB を超えると色が変わり、次の読み上げで自動で再起動して戻す。押すと、すぐに再起動する |
| ⌘ キー / 「以上」 | 聞き取りの方式を切り替える |
| 1x | 読み上げの速さを、1 倍と 1.25 倍で切り替える。読み上げの途中でも効く |
| ◐ | ウィンドウの色を、暗い色と明るい色で切り替える |
| ? | 操作と合図音の一覧を出す |
| 左下のつまみ | 読み上げの位置。動かすと、その少し手前から読み直す。読み終えた部分は、字幕が明るくなる |
| 帯、右下のつまみ、× | 動かす、大きさを変える、隠す。隠しても、次の発言でまた出る |

### 裏で作業しているセッションに話しかける

Claude が、時間のかかる調査などを裏で走らせて結果を待っている間は、そのセッションのタブに青の輪が出る。このとき、セッションは順番を持たないので、ほかのセッションと話せる。

青の輪のタブを押すと、そのセッションが「はい、どうぞ」と言って聞き取りに入る。「やっぱり止めて」「この点も調べて」などを、声で伝えられる。話し終えると、話す相手の選択は「すべて」に戻る。

### 読み上げのメモリを戻す

読み上げ(Kokoro)は、Mac の GPU で動く。文の長さが変わるたびに、GPU 用の計算の手順を組み立てて取っておくため、使うほどメモリが増える(半日ほど使い続けて 16GB になったことがある)。

8GB を超えると、次の読み上げの音が出始めたときに、自動で Kokoro を再起動して、起動直後の量に戻す。読む音声は先に作ってあるので、読み上げは止まらない。聞き取り(Whisper)は再起動しないので、その間に話した発言も届く。再起動には 10 秒ほどかかり、その間に来た次の読み上げは、失敗にせず、戻るまで待ってから話す。再起動の直後は、読み上げ中のつまみと速さの切り替えが、戻るまで待たされる。続けて再起動しないよう、自動の再起動は 5 分に 1 回までにしている。

すぐに戻したいときは、字幕ウィンドウの「メモリ」のボタンを押す。確認は出ない。Claude Code から `voice.sh restart-kokoro` でも同じことができる。

## 音声でメモを取る

会話の途中で思いついた「あとでやること」を、声で残せる。メモは、そのプロジェクトの `TODO.md` に、Claude が書き足す。

| 場面 | 操作 |
|---|---|
| Claude が返事を待っているとき | キーを押し、合図のあとに「メモ、(内容)」と言って離す。会話は途切れない |
| Claude が作業しているとき | キーを押し続け、合図(2 秒ほどあと)が鳴ってから内容を話して、離す |

押してから離すまでが、1 件のメモになる。メモと返事は、キーをいったん離して分ける。

## 英語や固有名詞を、正しく扱う

声では「ギットハブ」と読む語も、字幕には「GitHub」と出る。数字も、字幕には「2 つ」と出て、声では正しく読む。

固有名詞の読み方や、聞き取りの誤りは、会話の中で教えられる。

| 言い方 | 働き |
|---|---|
| 「(語)は(読み)と読んで」 | その読みで読み上げる。聞き取りでも、その語が正しく認識されやすくなる |
| 「(聞き間違い)と出たら(語)に直して」 | 聞き取りの結果を、登録した語に直す |

教えた内容は、個人用の辞書(`~/.voicemode/10-voice-yomi.tsv`)に入り、開いているすべての Claude Code に効く。

## 複数のプロジェクトで同時に使う

話すのは、一度に 1 つだけ。自動で順番待ちになり、切り替わるときは、プロジェクトの名前を名乗る。自分が話し終えるまでは、ほかは話しかけてこない。話す相手は、字幕ウィンドウのタブで選べる。

同じプロジェクトから Claude Code を 2 つ開いたときは、あとから始めたほうの名前に番号が付く(例:「設計」と「設計 2」)。タブも、順番も、メモも、別々に扱われる。どちらが「2」かは、切り替わるときの名乗りで分かる。

名前は、自分で付けることもできる。`/10-voice 調査` のように、言葉を付けて始めると、その言葉がタブの名前と名乗りになる。Claude Code を終えるまで有効で、付け直すこともできる。

## 話し方を分析する

`/10-voice review` で、その日の会話の記録から、指示の出し方や口ぐせを分析して、改善の案を報告する。前回との比較も出る。報告は、Mac 上(`~/.voicemode/10-voice-reviews/`)だけに置かれる。

## 確認待ちを音声で知らせる

Claude Code が、実行の確認を画面に出して止まると、「(名前)、確認待ちです。画面を見てください」と話す。[セットアップ手順](セットアップ手順.md)の手順 7 を設定した場合に働く。

## 使用量を抑える

音声の 1 往復ごとに、そのセッションの会話の履歴の全部が、Claude に送られる。履歴が大きいセッションで話し続けると、使用量が増える。

- 新しい話は、新しいセッションで始める。話題が片づいたら、`/clear`(履歴を消す)か `/compact`(履歴を要約に置き換える)を入力する
- 履歴が 20 万トークンを超えると、Claude が、話題の区切りや、会話を終えるときに、声で `/compact` を勧める。`/clear` と `/compact` は、Claude からは実行できないので、利用者が入力する
- 自動で `/compact` が働く大きさを、下げておくこともできる。`/autocompact 300k` と入力するか、`~/.claude/settings.json` に `"autoCompactWindow": 300000` を足す(Claude Code 2.1.304 以降)
- 1 時間以上あけてから話すと、履歴の全部が送り直される。長く席を外す前に、`/compact` か `/clear` をしておくと安い
- 上位のモデルでなくても、音声会話は使える。雑談や軽い作業は、`/model` で軽いモデルに替えたセッションで行う

## 保存されるデータと注意点

| 項目 | 内容 |
|---|---|
| 会話の記録 | `~/.voicemode/10-voice-captions/` に、日付ごとのファイルで残る。自動では消えない。業務の内容を話した場合は、扱いに注意する |
| 音声の録音 | 保存されない。外部にも送信されない。例外は、音声認識の調査用のフォルダ(`~/.voicemode/10-voice-debug/`)を自分で作った場合で、フォルダがある間だけ、聞き取った音声と認識結果がそこに残る。調査が済んだら、フォルダごと削除する |
| 開けるファイル | Claude が画面に開けるのは、文書や画像のファイル(html、md、pdf、png など)と、`http` / `https` の URL だけ。アプリやコマンドのファイルは開かない |
| 読み上げの記録 | `~/.voicemode/10-voice-playlog.tsv` に、読み上げ 1 回ごとの時刻、音声の長さ、音の大きさ、出力の機器などが残る。声が出なかったときの調査に使う。読み上げた文は入らない |
| 預かったメモ | `~/.voicemode/10-voice-memos/` に置かれ、Claude に渡ると消える |
| 起動し直したとき | 停止ボタン、話す相手、「あとで」は、元に戻る。聞き取りの方式、読み上げの速さ、ウィンドウの色は、引き継がれる |
| イヤホンの音質 | マイクが開いている間は、通話並みの音質になる |
| マイク | Mac 本体のマイクも使える(`voice.sh mic builtin`)。合図までの待ちが短くなるが、Mac から離れると声を拾いにくい |
| 聞き間違い | 音声認識には、聞き間違いがある。固有名詞は、読み方を教えると出やすくなる |
| スピーカーで使う | 確かめていない。「以上」の方式では、読み上げの声をマイクが拾い、読み上げが止まるおそれがある |
| キーの状態を調べられない環境 | 自動で、「以上」の方式になる |
