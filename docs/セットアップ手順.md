# 音声会話のセットアップ手順

Claude Code と音声で会話する環境を、Apple シリコンの Mac に作る手順。音声認識と読み上げは Mac 内だけで動かす。2026-11-18 に macOS 26.6.2、Claude Code 2.1.327 で実施した内容に基づく。

## 前提

- Homebrew、`uv`、Claude Code が入っている
- 字幕の窓を使う場合は、Xcode のコマンドラインツール(`swiftc`)が入っている。なければ `xcode-select --install` で入れる
- ディスクの空きが 5GB 以上ある(音声認識のモデルだけで約 2.6GB)
- 環境変数 `OPENAI_API_KEY` を設定していない

## 1. 依存するパッケージを入れる

```
brew install ffmpeg portaudio cmake
```

`cmake` は whisper.cpp のビルドに使う。

## 2. VoiceMode を入れる

版を固定して入れる。`uvx --refresh` で起動する方法は、起動のたびに最新版へ更新されるので使わない。

```
uv tool install 'voice-mode==9.0.2'
~/.local/bin/voicemode --version
```

## 3. 接続先を Mac 内だけにする

サービスを起動する前に設定する。既定値は「ローカル、次に OpenAI」の順になっている。

```
~/.local/bin/voicemode config set VOICEMODE_TTS_BASE_URLS http://127.0.0.1:8880/v1
~/.local/bin/voicemode config set VOICEMODE_STT_BASE_URLS http://127.0.0.1:2022/v1
~/.local/bin/voicemode config set VOICEMODE_WHISPER_LANGUAGE ja
~/.local/bin/voicemode config set VOICEMODE_WHISPER_MODEL large-v3-turbo
~/.local/bin/voicemode config set VOICEMODE_VOICES jf_alpha
~/.local/bin/voicemode config set VOICEMODE_KOKORO_DEFAULT_VOICE jf_alpha
```

設定は `~/.voicemode/voicemode.env` に書き込まれる。

## 4. Whisper と Kokoro を入れる

```
~/.local/bin/voicemode service install whisper
~/.local/bin/voicemode whisper model large-v3-turbo
~/.local/bin/voicemode service install kokoro
```

確認の質問が出たら `Y` で進める。Kokoro は初回の起動に数分かかる。

## 5. 待ち受けを Mac 内だけにする

導入直後の起動スクリプトは `0.0.0.0` で待ち受け、同じネットワークの他の端末から接続できる。`127.0.0.1` に書き換える。

```
sed -i '' 's/--host 0\.0\.0\.0/--host 127.0.0.1/g' \
  ~/.voicemode/services/whisper/bin/start-whisper-server.sh \
  ~/.voicemode/services/kokoro/start-gpu_mac.sh
```

VoiceMode を再導入または更新すると元に戻ることがある。`voice.sh on` が毎回確かめて直す。

## 6. Claude Code に登録する

```
claude mcp add --scope user voicemode -- ~/.local/bin/voicemode-mcp-launcher
claude mcp list
```

`voicemode` が `Connected` と表示されれば登録できている。登録後に始めたセッションから使える。

## 7. スキルを置く

このリポジトリを clone する。スキルの本体は `skills/10-voice/` にある。ホームディレクトリからシンボリックリンクを張って使う。

```
ln -s <このリポジトリの場所>/skills/10-voice ~/.claude/skills/10-voice
```

リポジトリを別の場所へ移したら、リンクを張り直す。

## 8. 動作を確かめる

```
~/.claude/skills/10-voice/scripts/voice.sh on
~/.claude/skills/10-voice/scripts/voice.sh status
```

次のように表示されれば、起動と待ち受けの限定ができている。

```
whisper: 起動中(127.0.0.1:2022 )
kokoro: 起動中(127.0.0.1:8880 )
```

`on` は字幕の窓も出す。初回は `caption.swift` をビルドするので、数秒かかる。

新しい Claude Code のセッションで `/10-voice` と入力するか、「音声で会話しよう」と伝える。Claude が話しかけ、合図の音が鳴ったら話す。話し終わったら「以上」と言う。

## 話し方

- 合図の音が鳴ってから話し始める
- 考えて黙っている間も、録音は切れない
- 話し終わったら「以上」と言う。「以上です」でもよい。終了の合図音が鳴り、Claude に発言が届く
- 「三つ以上」「これ以上」のように、数量や比較に続く「以上」では終わらない。数字の直後で終えたいときは、少し間をおいて「以上」と言う
- 「以上」を言わないまま 60 秒黙ると、そこまでの発言が届く
- Claude の読み上げ中に話しかけると、読み上げが止まり、聞き取りに入る。咳や物音で止まった場合は「続けて」と言う
- 「ミュート」とだけ言うと、マイクが閉じる。再開するときは、キーボードで `/10-voice` と入力する
- Claude が作業している間は、マイクは閉じている。次の合図を待って話す
- 複数のセッションで同時に使うと、自動で順番待ちになる。別のセッションに切り替わるときは、最初にプロジェクト名を名乗る
- 読み上げた文と、認識された発言は、字幕の窓に出る。上の帯をつかむと動かせ、右端の × で隠せる。隠しても、次の読み上げや発言でまた出る
- 会話中は、イヤホンの音が通話並みの音質になる。マイクを開いている間、イヤホンが通話用の接続に切り替わるため

## 日々の使い方

| 場面 | 操作 |
|---|---|
| 音声で会話する | Claude Code で `/10-voice`、または「音声で会話しよう」 |
| 出社日など、使わないとき | `/10-voice off`、または `~/.claude/skills/10-voice/scripts/voice.sh off` |
| 状態を見る | `/10-voice status` |

`off` はサービスを止め、ログイン時の自動起動も解除する。次に `on` を実行するまで起動しない。起動中は 3GB ほどメモリを使う。

## うまくいかないとき

| 症状 | 確かめること |
|---|---|
| 声が検出されず、打ち切りで終わる | 「システム設定 > サウンド > 入力」で、話しながら入力レベルが動くかを見る。ノイズキャンセリング付きのイヤホンは、話していない間は完全な無音を送るので、無音の録音だけでは故障と判断できない |
| 声が聞こえない | Mac の出力が消音になっていないか、出力先がイヤホンになっているかを見る。イヤホンの接続が切れると、入力と出力が Mac 本体に切り替わる |
| 聞き取りの状況を調べたい | `~/.claude/skills/10-voice/scripts/voice.sh listen --verbose` を実行する。区切りごとの認識結果、声と判定した数、最大音量が表示される |
| `voice.sh on` がエラーで止まる | 表示された理由を直す。接続先にローカル以外の URL がある、`OPENAI_API_KEY` が設定されている、待ち受けが `127.0.0.1` だけになっていない、のいずれか |
| Claude が音声のツールを使えない | `claude mcp list` で `voicemode` が `Connected` かを見る。登録後にセッションを始め直す |
| 字幕の窓が出ない | `~/.claude/skills/10-voice/scripts/voice.sh captions on` を実行し、表示を見る。`swiftc` がない、またはビルドに失敗している場合は、その旨が出る |
| サービスが起動しない | `~/.local/bin/voicemode service logs whisper`(または `kokoro`)でログを見る |

## 元に戻す方法

```
~/.claude/skills/10-voice/scripts/voice.sh off
claude mcp remove --scope user voicemode
uv tool uninstall voice-mode
```

モデル、設定、字幕の窓のプログラム(`10-voice-caption`)は `~/.voicemode/` に、スキルへのリンクは `~/.claude/skills/10-voice` に残る。不要なら削除する。
