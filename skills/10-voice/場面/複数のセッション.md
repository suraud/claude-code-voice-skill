# 複数のセッション

- 複数のセッションで同時に使うと、自動で順番待ちになる。一度に 1 つのセッションだけが話して聞く。利用者が話し終える(キーを離す、または「以上」と言う)までは、そのセッションが順番を持つ。話し終えたあと(作業中)は、ほかのセッションが先に話しかけることがある。別のセッションから切り替わったときは、スクリプトが読み上げの最初にセッションの名前(Claude Code を始めたフォルダの名前)を名乗る。自分で名乗りを足さない。同じフォルダから Claude Code を 2 つ開いていると、あとから始めたほうの名前に番号が付き(「設計 2」)、別のセッションとして扱われる。利用者が名前を付けていれば(引数の表)、その名前になる。自分の名前は、`voice.sh on` と `voice.sh status` の出力の「セッション:」の行で分かる
- 利用者は、字幕の窓で、セッションのタブを押して話す相手を選べる。選ばれている間は、そのセッションだけが話す。「すべて」のタブを押すと、相手を選ばない状態に戻る。セッションの置き場所は「いま話す」と「あとで」の 2 つで、「あとで」のセッションは、戻されるか、話す相手に選ばれるまで話せない。話す相手と置き場所を、自分で変えない
- 実行の確認が画面に出て止まると、hook が設定されていれば、スクリプトが「(セッション名)、確認待ちです。画面を見てください」と話す(`voice.sh notify`)。自分では呼ばない。それでも、確認が出そうな操作の前には、声で「このあと画面に確認が出ます」と伝える
